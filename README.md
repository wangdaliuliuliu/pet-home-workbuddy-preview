# 宠物小家 WorkBuddy 桌面试用版

这是 Windows 上的独立试用包。请由家长在自己已登录的 WorkBuddy 上安装和试用。保存位置由安装者选择，数据存放在这份安装里的 `data/local-install`。界面在系统浏览器打开，录音使用浏览器的麦克风授权。

## 安装和打开

1. 由 WorkBuddy 克隆仓库或解压安装包到用户选定的位置。从包含 `package.json` 的目录执行 `npm run install:workbuddy`。需要 Node.js 22.13+。安装器会从开源社区准备 Python 工具和录音、免费朗读所需的模型。
2. 安装完成后会打开注册页并创建桌面「宠物小家 WorkBuddy 试用版」。保存 WorkBuddy 中进行的工作，正常退出 WorkBuddy，再双击这个桌面图标。若 WorkBuddy 已由本试用版启动，双击会复用。
3. 注册并创建测试宠物后，先随便聊一句、再追问刚才的话。换窗口或重启后，小家会从自己的本地存档组织近期上下文。
4. 结束试用时，正常退出 WorkBuddy 即可关闭其本机调试端口。下次从普通 WorkBuddy 图标打开会恢复正常启动。试用版按 WorkBuddy 自己的权限运行，请保留默认审批，遇到非预期授权提示应拒绝。

## 实现边界

- 仅在桌面试用版启动时请求开启本机调试通道。检测到 WorkBuddy 在普通模式运行会保留它，试用版不会强制重启。调试通道只有本机可访问，但同一台电脑内的其他程序也能连接。只适合家长在自用电脑上试用。
- 陪聊、故事文字、图片理解和生成通过已登录的 WorkBuddy 桌面任务执行。语音和线上串门仍按小家原有配置处理。试用时生成会消耗登录账户自身额度，具体见 WorkBuddy 用量。
- 已有宠物的名称、称呼、语言、近期对话和相关记忆沿用小家正式陪聊逻辑。每次只创建小家自己的桌面任务，正式聊天历史和宠物档案保存在小家。
- 试用包内含 [workbuddy-bridge 2.3.0](https://github.com/luoliabalabala/workbuddy-bridge) 的 MIT 许可源码。试用包去掉了强制终止 WorkBuddy 的启动路径。检测到正在工作的任务时，小家会提示稍候。
